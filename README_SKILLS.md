# Claude Skills 快速安装

## 一键安装

```bash
python3 skill_install.py
```

这将自动安装：
- Document Skills (docx, pdf, pptx, xlsx)
- Example Skills (11+ 个示例技能)
- 配置插件市场

## 详细文档

查看 [CLAUDE_SKILLS_SETUP.md](./CLAUDE_SKILLS_SETUP.md) 获取完整的安装指南和使用说明。

## 快速验证

安装完成后，检查安装结果：

```bash
ls ~/.claude/skills/
```

应该看到 `document-skills` 和多个示例 skills 目录。
